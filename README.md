# Pisa Budget Calculator 💰🇮🇹

My second Python project for living in Pisa, Italy

## Loyiha haqida
Pisa da yashaydigan talabalar uchun oylik va yillik xarajatlarni hisoblaydigan dastur.

## Qanday ishlaydi?
Ijara, ovqat, transport, kitob xarajatlarini kiriting:
- Oylik xarajatni hisoblaydi
- Yillik xarajatni hisoblaydi
- Byudjetingizni baholaydi

## Misol
Ijara: 400€ + Ovqat: 200€ + Transport: 50€ + Kitob: 30€ = 680€/oy
